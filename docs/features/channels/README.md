# ภาพรวมช่องทาง

ลูกค้าติดต่อองค์กรได้หลายทาง ทุกทางเข้ากล่องข้อความเดียวกัน และทีมตอบจากที่เดียว ข้อความออกทางช่องทางเดิมของลูกค้าเอง

| ช่องทาง | ตั้งค่าที่ | เอกสาร |
|---|---|---|
| แชทบนเว็บ และปุ่มแชทบนเว็บไซต์ | ตั้งค่าองค์กร → แชทบนเว็บไซต์ | [หน้าช่วยเหลือและแชทผู้เยี่ยมชม](../support-page-and-guest-chat.md) |
| LINE Official Account | ตั้งค่าองค์กร → LINE / อีเมล / Facebook / Instagram → LINE | [LINE](line.md) |
| อีเมล | ตั้งค่าองค์กร → LINE / อีเมล / Facebook / Instagram → อีเมล | [อีเมล](email.md) |
| Facebook Messenger และ Instagram | ตั้งค่าองค์กร → LINE / อีเมล / Facebook / Instagram → Facebook และ Instagram | [Facebook และ Instagram](facebook-instagram.md) |
| บันทึกเอง | ทีมงานเปิดเคสเอง | [เคส](../tickets.md) |

## กติการ่วมของทุกช่องทาง

- **หนึ่งบัญชีต่อหนึ่งองค์กร** LINE OA กล่องอีเมล หรือเพจเดียวกัน ผูกได้องค์กรเดียว และเปลี่ยนบัญชีต้นทางของช่องทางที่ผูกแล้วไม่ได้
- **เฉพาะเจ้าขององค์กร** ตั้งค่าช่องทางได้
- **ความลับไม่ส่งกลับหน้าเว็บ** token รหัสผ่าน และ App Secret เข้ารหัสเก็บเป็นไฟล์ฝั่งเซิร์ฟเวอร์ ช่องรหัสผ่านในหน้าตั้งค่าเริ่มว่างเสมอ เว้นว่างไว้หมายถึงใช้ค่าเดิม
- **ขั้นตอนเชื่อมต่อ** แต่ละช่องทางมีขั้นตอนที่ติ๊กเองจากสิ่งที่ระบบเห็นจริง เช่น เข้าบัญชีได้ Webhook ชี้มาที่ระบบ และได้รับข้อความแรก ไม่ใช่แค่กรอกฟอร์มครบ ขั้นแรกที่ยังไม่เสร็จบอกว่าต้องทำอะไร
- **ทีมรับเรื่องใหม่** แต่ละช่องทางเลือกทีมที่รับเรื่องใหม่ได้ การเปลี่ยนทีมไม่ย้ายบทสนทนาเก่า
- **ปุ่มทดสอบ** ตรวจว่าเข้าบัญชีได้ โดยไม่ส่งข้อความถึงลูกค้า

## สถานะการส่ง

ข้อความตอบลูกค้าทาง LINE อีเมล Facebook และ Instagram บันทึกพร้อมคิวส่งใน transaction เดียวกัน แล้วงานเบื้องหลังจึงส่ง ใต้ข้อความแสดงสถานะ

| สถานะ | ความหมาย |
|---|---|
| รอส่ง หรือกำลังส่ง | อยู่ในคิว |
| บริการปลายทางรับข้อความแล้ว | ผู้ให้บริการยอมรับคำขอ ยังไม่ได้ยืนยันว่าลูกค้าได้รับหรืออ่าน SLA นับเป็นการตอบครั้งแรกตอนนี้ |
| ส่งไม่สำเร็จ | แสดงสาเหตุและปุ่ม **ลองส่งอีกครั้ง** ข้อผิดพลาดชั่วคราวลองเองสูงสุด 3 ครั้ง |
| ไม่ทราบผลการส่ง | อาจส่งแล้วแต่ไม่ได้รับคำยืนยัน ระบบไม่ส่งซ้ำเองและไม่มีปุ่มลองซ้ำ ให้ตรวจจากผู้ให้บริการก่อนส่งข้อความใหม่ |

- ก่อนส่ง งานเบื้องหลังตรวจสิทธิ์ของทีมงาน ทีม สถานะองค์กร และการตั้งค่าปัจจุบันอีกครั้ง
- การแก้การตั้งค่าเชื่อมต่อยกเลิกข้อความที่ยังรอส่ง ข้อความที่เริ่มส่งออกไปแล้วดึงกลับไม่ได้
- การแก้เฉพาะสิ่งที่ลูกค้าเห็น เช่น ชื่อผู้ส่งอีเมล ลายเซ็น หรือข้อความต้อนรับของ LINE ไม่ยกเลิกคิว
- หลังทีมตอบทางช่องทางภายนอก หน้าจอบอกว่าข้อความเข้าคิวส่งแล้ว

## เฝ้าช่องทาง

เมื่อ LINE อีเมล หรือ Facebook ขององค์กรหยุดทำงาน เช่น token ถูกเพิกถอน รหัสผ่านกล่องอีเมลถูกเปลี่ยน หรือเซิร์ฟเวอร์ไม่ตอบ เจ้าขององค์กรรู้ทันที ไม่ต้องรอให้ลูกค้าบอก

- งานเบื้องหลังตรวจทุกนาที กล่องอีเมลถูกดึงอยู่แล้วตลอด LINE และ Facebook ถูกถามเป็นระยะ และถี่ขึ้นขณะมีปัญหา การส่ง LINE ที่ล้มเหลวนับทันที
- ปัญหาที่เกินช่วงผ่อนผัน แจ้งครั้งเดียวทางอีเมลถึงเจ้าขององค์กรทุกคน และในกระดิ่ง บอกสาเหตุและลิงก์ไปที่ต้องแก้
- เมื่อกลับมาใช้ได้ แจ้งอีกครั้ง
- ผู้ดูแลแพลตฟอร์มเห็นช่องทางที่มีปัญหาของทุกองค์กรในภาพรวมระบบ และสั่งส่งข้อความที่ล้มเหลวซ้ำได้
