# LINE

รับและตอบข้อความจาก LINE Official Account ขององค์กร ทั้งแชทส่วนตัวและกลุ่ม ส่วนหนึ่งของ [ช่องทาง](README.md)

## เชื่อมต่อ

1. ใน LINE Developers เปิด Messaging API ของ Official Account แล้วคัดลอก **Channel Secret** และ **Channel Access Token**
2. ในระบบ ไปที่ **ตั้งค่าองค์กร → LINE / อีเมล / Facebook / Instagram → LINE** ใส่ค่าทั้งสอง เลือกทีมรับเรื่องใหม่ ติ๊ก **เปิดรับและส่ง LINE** แล้วบันทึก ระบบตรวจ Access Token และผูกบัญชีก่อนเปิดใช้
3. คัดลอก **Webhook URL** ไปใส่ใน LINE Developers เปิด **Use webhook** แล้วกด Verify
4. แนะนำให้เปิด Webhook redelivery เพื่อให้ LINE ส่งเหตุการณ์ที่รับไม่สำเร็จมาใหม่ และปิดข้อความตอบอัตโนมัติของ OA ไม่ให้ตอบซ้อนกัน
5. ส่งข้อความจาก LINE ในมือถือหาบัญชีนี้ แล้วดูในกล่องข้อความ

Webhook URL ต้องเป็น HTTPS สาธารณะ เช่น `https://support.example.com/api/webhooks/line/<route-id>` ใช้ localhost ไม่ได้

ขั้นตอนเชื่อมต่อในหน้าตั้งค่าตรวจได้ด้วยว่า LINE ส่ง Webhook มาที่ระบบนี้จริงหรือไม่ ถ้าชี้ไปที่อื่นจะบอกที่อยู่ที่ LINE ใช้อยู่

## การรับข้อความ

- ตรวจลายเซ็นจาก body ดิบก่อนอ่าน JSON ตรวจว่าเป็นบัญชีที่ผูกไว้ และกันเหตุการณ์ซ้ำด้วย `webhookEventId`
- บันทึกเหตุการณ์ลงคิวก่อนตอบ HTTP 200 แล้วงานเบื้องหลังจึงสร้างบทสนทนา
- ใช้ LINE user ID เป็นตัวตน ชื่อเริ่มต้นแสดงท้าย ID ไม่เรียกข้อมูลโปรไฟล์เพิ่ม
- รับข้อความ รูป PNG และ JPG และไฟล์ PDF และ TXT ตามขีดจำกัดไฟล์แนบของระบบ สื่ออื่นแสดงข้อความให้ไปดูใน LINE ต้นทาง
- ข้อความเก่าที่ LINE ส่งซ้ำมาช้า ไม่เปิดเคสที่ปิดแล้วกลับมา

## การตอบ

- ใช้ LINE Push API พร้อม retry key เดิมตั้งแต่ครั้งแรก ถ้าเครือข่ายขาด ระบบลองใหม่ด้วย key เดิม LINE จึงไม่ส่งซ้ำ ไม่ลองหลังผ่าน 23 ชั่วโมงนับจากเริ่มส่ง
- ข้อความยาวไม่เกิน 5,000 หน่วยอักขระ UTF-16 ต่อครั้ง (emoji บางตัวนับมากกว่าหนึ่ง)
- การส่งมีข้อจำกัดและค่าบริการตามแผนของ LINE OA
- การที่ LINE รับคำขอไม่ได้ยืนยันว่าผู้รับได้รับหรืออ่าน เช่น ผู้รับอาจบล็อกบัญชีไว้

## ส่งไฟล์ออกทาง LINE

LINE ดาวน์โหลดไฟล์จาก URL จึงต้องตั้ง **โดเมน HTTPS สำหรับส่งไฟล์** ที่เข้าถึงระบบได้จากภายนอก และ reverse proxy ต้องส่งต่อเส้นทาง `/api/channel-files/` มาที่ระบบ

- PNG และ JPG ไม่เกิน 1 MB ส่งเป็นข้อความรูปของ LINE
- PDF, TXT และรูปขนาดใหญ่ ส่งเป็นลิงก์ดาวน์โหลด ลิงก์หมดอายุ 7 วันหลังสร้าง
- ไม่เกิน 3 ไฟล์ รวม 5 MB
- ลิงก์สุ่มคาดเดาไม่ได้ ผู้ที่ได้ลิงก์ดาวน์โหลดได้ก่อนหมดอายุโดยไม่ต้องเข้าสู่ระบบ
- ไฟล์ในบันทึกภายในไม่มีลิงก์สาธารณะ
- ใต้ข้อความกด **ถอนลิงก์ไฟล์** เพื่อหยุดการดาวน์โหลดต่อได้ แต่เรียกคืนไฟล์ที่ปลายทางดาวน์โหลดไปแล้วไม่ได้
- การระงับองค์กรปิดลิงก์ทั้งหมดด้วย

## กลุ่ม LINE

1. ใน LINE Developers เปิด **Allow bot to join group chats**
2. ในระบบเปิด **รับและตอบในกลุ่ม LINE** แล้วเชิญ OA เข้ากลุ่ม

- ข้อความจากสมาชิกต่างคนในกลุ่มเดียวกันอยู่บทสนทนาเดียวกัน แชทส่วนตัวและกลุ่มอื่นแยกกัน
- คำตอบและไฟล์ส่งถึงสมาชิกทุกคนในกลุ่ม หน้าจอเตือนก่อนพิมพ์ตอบ
- ถ้าบอตออกจากกลุ่ม ข้อความที่รอส่งถูกยกเลิก และปิดการตอบจนกว่าบอตจะเข้ากลุ่มอีกครั้ง
- สมาชิกกลุ่มเปลี่ยน AI หยุด ให้ทีมงานตรวจและเปิดต่อเอง
- ให้ AI ตอบในกลุ่มต้องเปิดอีกสวิตช์ ดู [AI](../ai.md#กลุ่ม-line)

## ข้อความต้อนรับเพื่อนใหม่

เมื่อมีคนเพิ่มบัญชี LINE ขององค์กรเป็นเพื่อน ระบบส่งข้อความต้อนรับที่องค์กรเขียนเองได้ (ไม่เกิน 1,000 ตัวอักษร)

- ส่งครั้งเดียวต่อการเพิ่มเพื่อน ด้วยการตอบกลับของ LINE (reply) จึงไม่นับโควตาข้อความแบบ push
- การแก้ข้อความต้อนรับไม่ยกเลิกข้อความที่รอส่ง
- ตั้งที่การ์ด **ข้อความต้อนรับเพื่อนใหม่** ในหน้าตั้งค่า LINE

## ใช้ LINE แจ้งเตือนลูกค้า

ลูกค้าที่มีบัญชีและผู้เยี่ยมชม ผูก LINE ของตัวเองกับบัญชี LINE ขององค์กร เพื่อรับแจ้งเตือนเมื่อทีมตอบได้ ด้วยการส่งรหัส 6 หลักในแชท 1:1

- รหัสอายุ 10 นาที เก็บเป็นค่า hash รหัสใหม่แทนรหัสเดิม
- ผู้ส่งที่ส่งรหัสผิด 5 ครั้งในชั่วโมงเดียว ไม่ถูกตรวจจนครบชั่วโมง และรหัสผิดทุกครั้งนับกับรหัสที่ยังใช้ได้ทั้งหมด
- รหัสผิดถูกเก็บเป็นข้อความธรรมดา การลองจึงไม่เปิดเผยอะไร
- รหัสที่พิมพ์ในกลุ่ม LINE ถูกทิ้งและใช้ไม่ได้ทันที
- ข้อความแจ้งเตือนมีเพียงหัวเรื่องและลิงก์ ไม่มีเนื้อความ

ลูกค้าที่เริ่มแชทบนเว็บ ย้ายแชทเดิมไปคุยต่อใน LINE ได้ด้วยรหัสแบบเดียวกัน ดู [หน้าลูกค้า](../customer-portal.md#คุยต่อใน-line)
