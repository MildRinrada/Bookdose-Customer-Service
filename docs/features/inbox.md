# กล่องข้อความ

ที่ทีมงานอ่านและตอบลูกค้าทุกช่องทาง (`/inbox`) แชทบนเว็บ LINE อีเมล Facebook และ Instagram อยู่ในรายการเดียว ตอบจากที่เดียว ข้อความออกทางช่องทางเดิมของลูกค้าเอง

## บทสนทนากับเคสเป็นคนละอย่าง

- **บทสนทนา** คือที่คุยกับลูกค้า ทุกข้อความจากทุกช่องทางเป็นบทสนทนา
- **เคส** คืองานที่ต้องติดตาม เปิดจากบทสนทนาเมื่อเรื่องนั้นต้องทำต่อ

คำถามที่ตอบจบในแชทไม่จำเป็นต้องเปิดเคส บทสนทนาหนึ่งอยู่ได้ไม่เกินหนึ่งเคส แต่เคสหนึ่งมีได้หลายบทสนทนา ดู [เคส](tickets.md)

## รายการบทสนทนา

- กรองตามแท็บ ช่องทาง และคำค้น
- แต่ละแถวแสดงรูปของลูกค้า เวลา หัวเรื่อง ข้อความล่าสุด และบรรทัดสิ่งสำคัญ: รอเราตอบ ความเร่งด่วน ช่องทาง เลขเคส บริษัท
- บทสนทนาที่รอเราตอบเป็นตัวหนา นับจากข้อความสาธารณะล่าสุด บันทึกภายในไม่ล้างสถานะรอตอบ
- ลูกค้าที่ไม่พอใจมีป้าย **ไม่พอใจ** หรือ **โกรธมาก** และลูกค้าที่บอกว่ารอไม่ได้มีป้าย **ด่วน** ดู [AI](ai.md#อ่านอารมณ์ลูกค้า)
- ลูกค้าที่แชทโดยไม่มีบัญชีมีป้าย **ผู้เยี่ยมชม** พร้อมบอกว่าติดต่อกลับทางไหนได้
- เจ้าหน้าที่เห็นเฉพาะบทสนทนาของทีมตัวเอง
- จอกว้างเปิดบทสนทนาแรกให้เลย จอแคบแสดงรายการก่อน
- อัปเดตเองทุก 12 วินาที (ทุกนาทีเมื่อการอัปเดตสดเชื่อมต่ออยู่) โดยไม่แตะข้อความที่กำลังพิมพ์และตำแหน่งที่อ่านอยู่

## บทสนทนาที่เปิดอยู่

- หัวบทสนทนาบอกว่าคุยกับใคร มาจากช่องทางไหน เคสที่เชื่อมอยู่ และใครกำลังตอบ (AI หรือคน)
- จอกว้างมีแถบข้างแสดงข้อมูลลูกค้า ช่องทางติดต่อ หมวดเรื่อง เลขอ้างอิงที่ลูกค้าให้มา เคส และบทสนทนาอื่นของลูกค้าคนเดียวกัน
- ปุ่ม **เฉพาะบันทึกภายใน** แสดงเฉพาะการคุยกันในทีม
- ปิดหรือเปิดบทสนทนาได้ สถานะของบทสนทนาแยกจากสถานะของเคส
- ประกาศปัญหาที่องค์กรแจ้งลูกค้าอยู่แสดงเหนือกล่องข้อความด้วย ทีมจึงรู้ว่าลูกค้ากำลังอ่านอะไร

### มีคนกำลังตอบแชทนี้อยู่

แถบเหนือช่องพิมพ์บอกว่าเพื่อนร่วมทีมคนไหนเปิดแชทนี้อยู่ หรือกำลังพิมพ์ตอบ เพื่อไม่ให้สองคนตอบลูกค้าคนเดียวกันพร้อมกัน แถบนี้ไม่ล็อกอะไร และไม่แสดงเมื่ออยู่คนเดียวหรือการเชื่อมต่อหลุด

### กำลังพิมพ์และอ่านแล้ว

- ลูกค้าเห็น "กำลังพิมพ์…" เมื่อทีมพิมพ์ตอบ แต่ไม่เห็นเมื่อทีมเขียนบันทึกภายใน
- ใต้ข้อความล่าสุดแสดง "อ่านแล้ว" เมื่ออีกฝั่งเปิดอ่าน

## ช่องพิมพ์

| เครื่องมือ | ใช้ทำอะไร |
|---|---|
| ตอบกลับลูกค้า หรือ บันทึกภายใน | บันทึกภายในลูกค้าไม่เห็น พื้นที่พิมพ์เปลี่ยนสีให้รู้ว่ากำลังเขียนบันทึก |
| จัดรูปแบบ | ตัวหนา ตัวเอียง ขีดเส้นใต้ รายการ ลิงก์ เก็บเป็น Markdown |
| แนบไฟล์ | ไม่เกิน 3 ไฟล์ รวม 5 MB ลากไฟล์มาวางได้ |
| คำตอบสำเร็จรูป | พิมพ์ `/` ตามด้วยตัวอักษรแรก แล้วเลือกด้วยลูกศรและ Enter หรือกด Alt+1 ถึง Alt+9 สำหรับคำตอบด่วน 9 อันแรกของตัวเอง |
| ค้นคู่มือ | ค้นบทความด้วยภาษาพูด แล้วส่งลิงก์ให้ลูกค้า หรือแทรกเนื้อหาไว้แก้ก่อนส่ง |
| Macro | ปุ่มเดียวทำหลายขั้น ดู [ระบบอัตโนมัติ](automation.md#macro) |
| แท็กทีม | พิมพ์ `@ชื่อ` หรือ `@ทีม` ในบันทึกภายใน |
| AI ช่วยร่าง | AI ร่างคำตอบพร้อมแหล่งอ้างอิง ทีมงานตรวจแล้วนำใส่ช่องพิมพ์เอง ดู [AI](ai.md) |

- ข้อความที่ยังไม่ส่งจำไว้แยกต่อบทสนทนาขณะไปหน้าอื่น
- Ctrl+Enter ส่งข้อความ
- ความยาวสูงสุดตามช่องทาง: LINE 5,000 หน่วยอักขระ Facebook 2,000 ตัวอักษร Instagram 1,000 ตัวอักษร ข้อความทั่วไปไม่เกิน 20,000 ตัวอักษร

### คำตอบสำเร็จรูป 2 ชุด

| ชุด | ใครตั้ง | ตั้งที่ |
|---|---|---|
| ของทีม | เจ้าขององค์กร | ตั้งค่าองค์กร → มาตรฐานบริการ |
| ของตัวเอง (คำตอบด่วน) | สมาชิกแต่ละคน | ตั้งค่าบัญชี → คำตอบด่วนและคีย์ลัด |

ทั้งสองชุดแค่เขียนลงช่องพิมพ์ ต้องกดส่งเอง Macro จึงเป็นสิ่งที่ส่งข้อความได้ในคลิกเดียว

### @แท็ก

- พิมพ์ `@ชื่อสมาชิก` หรือกด **แท็กทีม** ในบันทึกภายใน `@ทีม` แท็กทุกคนในทีมของบทสนทนา
- ผู้ถูกแท็กที่มีสิทธิ์เห็นบทสนทนาเห็นในการ์ด **ถึงคุณ** และกระดิ่ง
- แจ้งในโปรแกรมเท่านั้น ไม่ส่งอีเมลหรือ LINE

## สถานะการส่ง

ใต้ข้อความที่ส่งทาง LINE อีเมล Facebook หรือ Instagram แสดงสถานะการส่ง และปุ่ม **ลองส่งอีกครั้ง** หรือ **ถอนลิงก์ไฟล์** เมื่อใช้ได้ ดู [ภาพรวมช่องทาง](channels/README.md#สถานะการส่ง)

ข้อความบนแชทเว็บแสดง "อ่านแล้ว" แทน เพราะลูกค้าอ่านบนหน้าเว็บโดยตรง

## แก้หรือถอนข้อความที่ส่งผิด

ทำได้เฉพาะแชทบนเว็บ เพราะข้อความที่ส่งผ่าน LINE อีเมล หรือ Facebook ไปถึงลูกค้าแล้วดึงกลับไม่ได้

- ผู้เขียนแก้ข้อความของตัวเองได้ ข้อความที่แก้จะบอกว่าแก้แล้ว
- ผู้เขียนหรือเจ้าขององค์กรถอนข้อความได้ ลูกค้าจะไม่เห็นอีก ส่วนทีมเห็นเครื่องหมายว่ามีข้อความถูกถอน
- ข้อความของลูกค้าแก้หรือลบไม่ได้

## ข้อความที่แปลแล้ว

เมื่อเปิดการแปลภาษาอัตโนมัติ ข้อความของลูกค้าที่ไม่ใช่ภาษาไทยแสดงเป็นภาษาไทยพร้อมต้นฉบับ และคำตอบภาษาไทยของทีมถูกแปลก่อนส่ง ดู [AI](ai.md#แปลภาษาอัตโนมัติ)

## ไฟล์แนบ

- ชนิดที่รับ: PNG, JPG, GIF, WebP, MP4, WebM, PDF และ TXT
- รูปและวิดีโอแสดงในบทสนทนา กดขยายได้ วิดีโอไม่เล่นเอง
- ไฟล์ในบันทึกภายในเปิดได้เฉพาะทีมงานที่มีสิทธิ์ในบทสนทนานั้น
- ไฟล์ส่วนตัวโหลดผ่าน API ที่ตรวจสิทธิ์ แล้วแสดงจาก URL แบบ `blob:` ในหน้าเท่านั้น
