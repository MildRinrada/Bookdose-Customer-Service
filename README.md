# Bookdose Customer Service

ระบบบริการลูกค้าบนเว็บภาษาไทย ใช้ได้หลายองค์กรในระบบเดียว แต่ละองค์กรรับเรื่องจากแชทบนเว็บ LINE อีเมล Facebook และ Instagram มาไว้ในกล่องข้อความเดียว เปิดเคสติดตามงาน วัดเวลาตอบตาม SLA มีคลังความรู้ ระบบอัตโนมัติ รายงาน และผู้ช่วย AI

ขอบเขตของระบบคืองานบริการลูกค้าเท่านั้น คือ แชท เคส และคำถามที่พบบ่อย ไม่มีเรื่องเงิน สัญญา ใบแจ้งหนี้ หรือปฏิทินนัดหมาย

## ส่วนประกอบ

| ส่วน | เทคโนโลยี | โฟลเดอร์ | พอร์ตปกติ |
|---|---|---|---|
| หน้าเว็บ | Next.js 16, React 19, TypeScript | `frontend/` | 3000 |
| API และข้อมูล | Python 3.10 ขึ้นไป, FastAPI บน uvicorn | `backend/`, `app.py` | 8787 |
| ฐานข้อมูล | SQLite แยกไฟล์ต่อองค์กร และฐานข้อมูลกลาง 1 ไฟล์ | `data/` | ไม่มี |

เบราว์เซอร์คุยกับหน้าเว็บที่พอร์ต 3000 ที่เดียว หน้าเว็บส่งต่อทุกคำขอ `/api/*` ไปให้ API เอง

## เริ่มใช้งานเร็ว

ต้องมี Python 3.10 ขึ้นไป และ Node.js 20 ขึ้นไป

**Windows:** ดับเบิลคลิก `Start Bookdose.bat` แล้วเปิด http://localhost:3000

**macOS:** ดับเบิลคลิก `Start Bookdose.command` แล้วเปิด http://localhost:3000

**โหมดพัฒนา** (แก้โค้ดแล้วเห็นผลทันที) เปิด Terminal 2 หน้าต่าง

```sh
python -m pip install -r requirements.txt
python app.py
```

```sh
cd frontend
npm install
npm run dev
```

ครั้งแรกจะพบหน้าสร้างผู้ดูแลระบบ หรือรัน `python app.py --demo-users` ก่อน เพื่อใช้[บัญชีทดสอบ](docs/getting-started.md#บัญชีทดสอบ)ชุดเดียวกัน รายละเอียดทั้งหมดอยู่ใน [วิธีรันโค้ด](docs/getting-started.md)
