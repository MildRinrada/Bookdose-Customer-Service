# ประวัติการทำงานและถังขยะ

## ประวัติการทำงาน

หน้า `/audit` เฉพาะเจ้าขององค์กร บอกว่าใครทำอะไรเมื่อไร

- ตัวเลขบนสุด 3 ตัว: จำนวนกิจกรรมในช่วงนั้น ใครทำมากที่สุด และเรื่องสำคัญ
- ค้นหา เลือกช่วงเวลา เลือกคน และเลือกว่าจะแสดงงานของระบบเองหรือไม่
- ชนิดของกิจกรรมเป็นแท็บ แท็บ **สำคัญ** อยู่แรก
- จัดกลุ่มตามวัน ใหม่สุดก่อน แต่ละแถวบอกว่าใครทำอะไรกับอะไร งานของระบบใช้สัญลักษณ์ของ AI กิจกรรมที่ซ้ำกันพับเป็นแถวเดียว
- คำอธิบายเป็นภาษาไทย รหัสทางเทคนิคอยู่ในรายละเอียด

รายการเดียวกันนี้ใช้ในประวัติของหน้าเคส และในคอนโซลระบบกลางสำหรับประวัติของแพลตฟอร์ม

### สิ่งที่บันทึก

- การเปลี่ยนเคส พร้อมค่าก่อนและหลัง
- การตั้งค่าองค์กร ช่องทาง ระบบอัตโนมัติ และ AI
- สมาชิก คำเชิญ และสิทธิ์เข้าช่วยเหลือ
- การลบ การกู้คืน และการล้างถาวร
- งานของระบบ เช่น ปิดเคสเมื่อลูกค้าเงียบ และล้างข้อมูลตามระยะเวลาเก็บ

ไม่บันทึกรหัสผ่าน token หรือเนื้อความ

ตาราง `audit_logs` มีทั้งในฐานข้อมูลกลาง (ประวัติของแพลตฟอร์ม) และในฐานข้อมูลของทุกองค์กร (ประวัติขององค์กร) และไม่ถูกลบ

## ถังขยะ

หน้า `/trash` เฉพาะเจ้าขององค์กร

การลบไม่ได้ทิ้งข้อมูลทันที แต่ย้ายภาพของทุกแถวที่ถูกลบมาเก็บไว้ การกู้คืนจึงเขียนกลับสิ่งที่เคยมีได้ครบ ไม่ต้องสร้างใหม่หรือเดา

- เก็บ 30 วัน แล้วล้างถาวรเอง
- แต่ละรายการบอกว่าเป็นอะไร ใครลบ และจะเก็บอีกนานเท่าไร
- **กู้คืน** เป็นทางที่ปลอดภัย จึงทำได้ทันที
- **ล้างถาวร** ต้องพิมพ์ยืนยันแบบเดียวกับตอนลบ
- การลบ การกู้คืน และการล้างถาวร บันทึกในประวัติการทำงานทุกครั้ง
- การลบยังต้องตั้งใจ แต่ละโมดูลถามก่อนลบ และไม่ยอมลบสิ่งที่ยังมีข้อมูลอื่นผูกอยู่ ถังขยะมีไว้กันการลบผิดชิ้น

เครื่องมือ PDPA ทิ้งสำเนาของบุคคลในถังขยะด้วย เมื่อสั่งลบข้อมูลบุคคล
