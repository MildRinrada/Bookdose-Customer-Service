## การตรวจสอบ

- Python integration tests ผ่านครบ 75 รายการ ตรวจการแยกองค์กร สิทธิ์ Validation โปรไฟล์ การระงับ การสมัคร/ยืนยัน และระบบช่องทางเดิม
- `node tests/browser-review.cjs` ตรวจการใช้งานตามรายการ Excel บนเดสก์ท็อปและมือถือ รวมรูปโปรไฟล์ Markdown/Script ตัวกรอง การส่งออก การเตือนทิ้งบทความ และขนาดข้อความ
- ผ่านชุดเบราว์เซอร์ทั้ง 5 ชุด: ระบบหลัก, Excel review, AI, LINE/Email และ OAuth ใช้บริการจำลองและฐานข้อมูลชั่วคราว ไม่ได้ส่งข้อความหรืออีเมลจริง
- ภาพหน้าจออยู่ใน `test-results/review-*.png` (ไม่รวมใน Git)

ข้อจำกัด: การปรับสีและขนาดนี้ไม่ได้เป็นการรับรอง WCAG ทั้งผลิตภัณฑ์ ตัวกรอง Audit ทำงานกับประวัติล่าสุดที่ระบุในหน้า และการกู้รหัสผ่านใช้ข้อความติดต่อผู้ดูแลตามทางเลือกใน Excel ส่วนอีเมลยืนยันการสมัครยังต้องตั้งค่า SMTP/โดเมนจริงก่อนใช้งาน
