# ข้อมูลลูกค้า

รายชื่อลูกค้าขององค์กร (`/contacts`) ทั้งที่ทีมงานเพิ่มเอง และที่ระบบสร้างเมื่อลูกค้าติดต่อเข้ามาทางช่องทางต่าง ๆ

## ใครเห็นใคร

- เจ้าขององค์กรเห็นลูกค้าทุกคน
- เจ้าหน้าที่เห็นลูกค้าที่ตัวเองสร้าง หรือที่มีงานอยู่ในทีมของตัวเอง

## รายการลูกค้า

- ค้นหา ตัวกรองด่วน กรองตามองค์กร (บริษัท) และเรียงตามชื่อ ช่องทางติดต่อ จำนวนเคส หรือการติดต่อล่าสุด
- แบ่งหน้า
- แต่ละแถวแสดงจำนวนเคสค้างและเคสที่เกิน SLA กดแล้วเปิดรายการเคสของลูกค้าคนนั้น
- วางเมาส์หรือโฟกัสที่ชื่อ แสดงการ์ดสรุป: ความพอใจที่ผ่านมา ช่องทางที่มักติดต่อ บันทึก และเคสล่าสุด โดยไม่ต้องออกจากรายการ

## ข้อมูลของลูกค้าหนึ่งคน

| กลุ่ม | ข้อมูล |
|---|---|
| ตัวตน | ชื่อ นามสกุล อีเมล เบอร์โทร องค์กร |
| การดูแล | ช่องทางและเวลาที่สะดวกให้ติดต่อ ภาษาที่ใช้ตอบ ป้ายของทีม คำเตือนที่แสดงบนแชทและเคสของลูกค้า บันทึก |
| ช่องทางที่เคยคุย | LINE อีเมล Facebook Instagram (อ่านอย่างเดียว) |
| ความยินยอม | ยินยอมให้ติดต่อกลับ และคำขอลบข้อมูล |
| ประวัติ | ใครแก้ล่าสุด และเคสทั้งหมดของลูกค้า |

- ชื่อและนามสกุลเก็บแยกกัน ชื่อเดิมที่เป็นช่องเดียวไม่ถูกแยกเองอัตโนมัติ เพราะเดาผิดได้
- อีเมลที่ซ้ำกับลูกค้าคนอื่นขึ้นคำเตือน แต่ไม่บังคับ
- **ภาษาที่ใช้ตอบ** ที่ทีมเลือกเอง ชนะภาษาที่ระบบตรวจพบ เมื่อเปิดการแปลภาษาอัตโนมัติ
- **คำเตือน** แสดงบนแชทและเคสของลูกค้าคนนั้น ทีมจึงเห็นก่อนตอบ
- **คำขอลบข้อมูล** แสดงในรายการคำขอของเครื่องมือ PDPA ในคอนโซลระบบกลาง ดู [คอนโซลระบบกลาง](platform-console.md#เครื่องมือ-pdpa)
- บันทึกข้อมูลลูกค้าแล้วเปิดเคสต่อได้ทันที

## รวมรายชื่อซ้ำ

ลูกค้าที่มีอีเมลเดียวกันรวมเป็นคนเดียวได้

1. เลือกคนที่จะเก็บไว้
2. เคสและบทสนทนาของคนอื่นย้ายมาที่คนนี้
3. รายชื่ออื่นถูกลบ

- การรวมย้ายสิทธิ์ของบัญชีลูกค้าตามไปด้วย
- ลบรายชื่อที่เป็นบัญชีลูกค้าไม่ได้
- แชทที่ผู้เยี่ยมชมเริ่มยังเป็นของผู้เยี่ยมชมคนนั้นแม้ทีมงานรวมรายชื่อแล้ว

## ลูกค้าที่ระบบสร้างเอง

| มาจาก | ชื่อเริ่มต้น |
|---|---|
| LINE | ท้าย LINE user ID ไม่เรียกข้อมูลโปรไฟล์เพิ่ม |
| Facebook | ท้าย PSID |
| Instagram | "Instagram" ตามด้วยท้าย ID |
| อีเมล | จากผู้ส่ง |
| แชทผู้เยี่ยมชม | ชื่อที่ผู้เยี่ยมชมกรอก หรือ "ผู้เยี่ยมชม" |

เรื่องใหม่ไม่รวมกับลูกค้าเดิมเพียงเพราะมีอีเมลหรือหัวเรื่องเหมือนกัน
