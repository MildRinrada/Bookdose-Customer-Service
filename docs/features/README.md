# สารบัญฟีเจอร์

แต่ละฟีเจอร์มีเอกสารของตัวเอง บอกว่าใครใช้ ใช้ทำอะไร ทำงานอย่างไร มีกติกาและข้อจำกัดอะไร และโค้ดอยู่ที่ไหน

## งานประจำวันของทีม

| ฟีเจอร์ | เนื้อหา |
|---|---|
| [ภาพรวม](dashboard.md) | รับงานถัดไป SLA Watch คาดว่าจะเกิน SLA แชทรอตอบ ส่งต่อกะ มุมมองของเจ้าขององค์กร |
| [กล่องข้อความ](inbox.md) | ทุกช่องทางในที่เดียว ตอบกลับ บันทึกภายใน @แท็ก ค้นคู่มือ คำตอบสำเร็จรูป |
| [เคส](tickets.md) | สถานะ 6 แบบ การมอบหมาย พักเคส ติดตามผล และการเปิดซ้ำ |
| [SLA และเวลาทำการ](sla-and-business-hours.md) | เวลาตอบกลับ SLA ตามความเร่งด่วน เวลาทำการ วันหยุด ข้อความนอกเวลา |
| [ข้อมูลลูกค้า](contacts.md) | รายชื่อลูกค้า โปรไฟล์การดูแล รวมรายชื่อซ้ำ |
| [คลังความรู้](knowledge-base.md) | บทความภายในและสาธารณะ ค้นหาด้วยภาษาพูด ประวัติการแก้ไข แม่แบบ |

## ระบบช่วยงาน

| ฟีเจอร์ | เนื้อหา |
|---|---|
| [ระบบอัตโนมัติ](automation.md) | กฎรับเรื่อง ยกระดับ SLA Macro แบบประเมิน CSAT ปิดเคสเมื่อลูกค้าเงียบ |
| [AI](ai.md) | ร่างคำตอบ Chatbot ผู้ช่วย AI สรุปบทสนทนา อ่านอารมณ์ แปลภาษา |
| [รายงาน](reports.md) | ตัวเลขบริการ ตารางแยกมิติ ความเร็วกับความพอใจ พยากรณ์จำนวนเคส ชุดข้อมูลสำหรับวิเคราะห์ |

## ช่องทางติดต่อ

| ฟีเจอร์ | เนื้อหา |
|---|---|
| [ภาพรวมช่องทาง](channels/README.md) | สถานะการส่ง คิวส่ง เฝ้าช่องทาง |
| [LINE](channels/line.md) | LINE OA แชทส่วนตัวและกลุ่ม ไฟล์ ข้อความต้อนรับเพื่อนใหม่ |
| [อีเมล](channels/email.md) | IMAP และ SMTP OAuth ของ Google และ Microsoft ชื่อผู้ส่งและลายเซ็น |
| [Facebook และ Instagram](channels/facebook-instagram.md) | Messenger และ DM Instagram ผ่านเพจเดียวกัน |

## ฝั่งลูกค้า

| ฟีเจอร์ | เนื้อหา |
|---|---|
| [หน้าช่วยเหลือและแชทผู้เยี่ยมชม](support-page-and-guest-chat.md) | หน้าขององค์กร แชทโดยไม่มีบัญชี ลิงก์ติดตาม ปุ่มแชทบนเว็บไซต์ แบนเนอร์ |
| [หน้าลูกค้า](customer-portal.md) | บัญชีลูกค้าใช้ได้ทุกองค์กร แชท เคส การแจ้งเตือน คุยต่อใน LINE |
| [ประกาศปัญหาและหน้าสถานะ](known-issues-and-status.md) | แจ้งลูกค้าเมื่อระบบขององค์กรมีปัญหา และหน้าสถานะของแพลตฟอร์ม |
