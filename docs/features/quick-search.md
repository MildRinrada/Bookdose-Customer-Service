# ค้นหาด่วน

ช่องค้นหาบนแถบด้านบนของทุกหน้าในพื้นที่ทำงาน (ยกเว้นกล่องข้อความบนจอคอม ซึ่งไม่มีแถบด้านบน) ใช้ไปหาเคส ลูกค้า บทความ หรือหน้าตั้งค่าได้ทันที ไม่ต้องเปิดรายการแล้วค้นหาอีกรอบ

## ใช้อย่างไร

- กด Ctrl+K (⌘K บน Mac) จากหน้าไหนก็ได้ หรือคลิกที่ช่องค้นหา ใช้ได้ทั้งแป้นพิมพ์ภาษาไทยและภาษาอังกฤษ
- พิมพ์แล้วผลลัพธ์ขึ้นใต้ช่องทันที แบ่งเป็น 4 กลุ่ม คือ เคส ลูกค้า บทความ และหน้าและการตั้งค่า กลุ่มละไม่เกิน 5 รายการ
- เลือกด้วยลูกศรขึ้นลงแล้วกด Enter หรือคลิกที่รายการ
- Esc ล้างคำค้น กดอีกครั้งเพื่อออกจากช่อง
- กด Enter โดยยังไม่ได้เลือกรายการ จะไปหน้ารายการเคสพร้อมคำค้น เหมือนที่ช่องนี้เคยทำ แถวสุดท้ายของผลลัพธ์บอกทางนี้ไว้ด้วย
- บนมือถือ รายการผลลัพธ์กว้างเกือบเต็มจอ ไม่ล้นออกด้านข้าง

## ค้นหาอะไรได้บ้าง

| กลุ่ม | ค้นจาก | กดแล้วไปที่ |
|---|---|---|
| เคส | เลขเคส (BD-1024, bd1024, #1024 หรือ 1024 และเลขที่ยังพิมพ์ไม่ครบ) หัวข้อ ชื่อลูกค้า | หน้าเคส |
| ลูกค้า | ชื่อ อีเมล ชื่อองค์กรของลูกค้า และเบอร์โทร (พิมพ์แบบมีขีด เว้นวรรค หรือติดกันก็เจอ) | หน้าข้อมูลลูกค้า กรองเฉพาะคนนั้น |
| บทความ | ชื่อบทความ และหมวด | หน้าบทความ |
| หน้าและการตั้งค่า | ชื่อและคำอธิบายของหน้า ส่วนต่าง ๆ ของตั้งค่าองค์กร และแท็บของตั้งค่าบัญชี | หน้านั้น |

- เคสเรียงเลขที่ตรงพอดีก่อน แล้วเป็นเคสที่ยังไม่เสร็จ แล้วเป็นเคสที่เปลี่ยนล่าสุด
- คำที่ตรงกับที่พิมพ์เป็นตัวหนาในชื่อของแต่ละรายการ
- เครื่องหมาย % และ _ ที่พิมพ์ถูกค้นตามตัวอักษร ไม่ได้แทนอักษรอื่น
- หน้าข้อมูลลูกค้าที่เปิดจากผลค้นหาล้างตัวกรองด่วนและตัวกรององค์กรที่เลือกไว้ครั้งก่อน ลูกค้าคนนั้นจึงไม่ถูกตัวกรองซ่อน

## สิทธิ์

ค้นเจอเฉพาะสิ่งที่เปิดได้อยู่แล้ว

- เจ้าหน้าที่เจอเฉพาะเคสของทีมตัวเอง และลูกค้าที่รายชื่อลูกค้าแสดงให้เห็น (สร้างเอง หรือมีงานในทีม) ใช้ตัวกรองเดียวกับรายการเคสและรายชื่อลูกค้า
- บทความเจอทั้งคลัง เพราะทุกคนในองค์กรอ่านคลังความรู้ได้
- หน้าตั้งค่าองค์กรขึ้นเฉพาะเจ้าขององค์กร
- คำตอบของ API ไม่ถูกเก็บในแคช (`Cache-Control: no-store`)
